# معرض تطبيقاتي — دليل الإعداد

## 1) إعداد الاتصال
افتح `config.js` واستبدل:
`PASTE_YOUR_SB_PUBLISHABLE_KEY_HERE`
بمفتاح `sb_publishable_...` الخاص بمشروعك.

لا تضع أبداً `sb_secret_...` أو `service_role` في ملفات الموقع أو في المتصفح.

Project URL الموجود في الإعدادات هو:
`https://dapowfuukeenirzemyzl.supabase.co`

## 2) متطلبات Supabase
- Storage bucket: `apks`
- الجدول: `public.apps`
- حقول الجدول: `id`, `name`, `description`, `version`, `storage_path`, `created_at`
- تسجيل دخول الأدمن عبر Supabase Auth بالبريد وكلمة المرور.

## 3) مراجعة مهمة قبل التشغيل
الأوامر السابقة في المحادثة أنشأت سياسات مرتبطة بمعرّف UID محدد. لا تعتمد على إخفاء زر الأدمن في الواجهة كحماية؛ الحماية الفعلية يجب أن تكون عبر RLS وسياسات Storage.
افتح SQL Editor ونفّذ `supabase-security.sql` بعد استبدال `PUT_ADMIN_USER_UUID_HERE` بمعرّف UID الصحيح لحسابك من Authentication → Users.
إذا كانت لديك سياسات قديمة متعارضة، راجعها واحذفها/استبدلها قبل إضافة السياسات الجديدة. لا تشغّل سياسات جديدة عشوائياً.

## 4) تشغيل الموقع
ارفع محتويات هذا المجلد إلى استضافة مواقع ثابتة تدعم HTTPS (مثل GitHub Pages أو Netlify أو Cloudflare Pages).
افتح رابط الموقع، ثم اضغط «دخول الأدمن»، وسجّل الدخول بحساب Supabase Auth.
بعدها يمكنك إضافة تطبيقات APK من لوحة التحكم.

## 5) ملاحظات
- هذه نسخة أولية عملية للواجهة والإدارة، وليست تطبيقاً منشوراً بعد.
- Public bucket يجعل التنزيل متاحاً لمن لديه رابط الملف. سياسات الرفع والحذف يجب أن تقتصر على UID الأدمن.
- لا توجد حالياً ميزة عدّ التحميلات أو تعديل بيانات التطبيق من الواجهة؛ يمكن إضافتها في مرحلة لاحقة.
- حد حجم الملف في Supabase يعتمد على إعدادات المشروع والخطة. لا تضع حداً منخفضاً يمنع ملفات APK الخاصة بك.
